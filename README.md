# AI Document Digitizer (LLM Agents Pipeline)

Агентная система для оцифровки рукописных и печатных документов с математическими формулами и перевода их в формат DOCX по ГОСТу.

## 🏗 Архитектура проекта
Пайплайн состоит из трех независимых модулей, управляемых через `main.py`:
1. **Vision Agent (`vision_agent.py`)**: Извлекает сырой текст и LaTeX-формулы из изображений с помощью Google Gemini Vision API.
2. **Markdown Encoder (`markdown_encoder.py`)**: LLM-агент, который очищает OCR-мусор, восстанавливает сломанный синтаксис LaTeX и верстает таблицы в Markdown.
3. **DOCX Builder (`converter.py`)**: Скрипт-сборщик, который парсит Markdown и генерирует нативный Word-документ.

## 👨‍💻 Мой вклад (DOCX Builder)
В рамках командной разработки я отвечал за проектирование и реализацию 3-го модуля (`converter.py`). 
**Ключевые фичи моего модуля:**
* **Парсинг Markdown:** Написан кастомный парсер с использованием регулярных выражений (Regex), устойчивый к вложенным математическим блокам.
* **Конвертация LaTeX в OMML:** Реализован алгоритмический перевод формул во внутренний формат Word (OMML) через `lxml` и XSLT-трансформации.
* **Обход XML-деревьев:** Написаны эвристики для исправления багов рендера сложных операторов (интегралы, системы уравнений, балансировка скобок).
* **Система Fallback:** При невозможности нативной конвертации OMML, формулы "на лету" рендерятся в PNG через `matplotlib` и вставляются в документ.

## 🛠 Стек технологий
